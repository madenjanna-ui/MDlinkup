# MD LinkUp — rebrand

- Название приложения изменено на **MD LinkUp**.
- Установлена утверждённая иконка с рукопожатием для PWA и iPhone.
- Обновлены экран входа, верхняя панель, боковое меню, настройки и уведомления.
- Общая стилистика и боковая панель сохранены.
- Рабочая логика чатов, WebSocket, групп, медиа, голосовых, реакций, звонков и push не менялась.
- Старые localStorage-ключи намеренно сохранены для совместимости с существующими пользователями.
