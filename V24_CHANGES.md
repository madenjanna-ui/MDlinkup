# Family 24.0 — удобство интерфейса

## Что изменено

- Фото и видео сначала открываются в окне предпросмотра. Можно добавить подпись или отменить; отправка начинается только по кнопке «Отправить».
- При отправке показан прогресс и ожидание подтверждения сервера. При неопределённом результате предложено сначала проверить чат, чтобы не отправить дубликат.
- Фото сжимаются до лимита 3 МБ; для видео исправлена проверка лимита — до 6 МБ. Лимиты указаны в двоичных мегабайтах.
- Кнопка ⋯ у сообщений открывает меню: ответ, копирование текста, избранное, редактирование своего текста, удаление при наличии прав. На сенсорном экране меню также открывается долгим нажатием.
- Удаление фото, видео, голосового или текста требует подтверждения. Уже сохранённые участниками копии не удаляются.
- Экран звонка различает вызов, подключение, состоявшееся соединение, разрыв и ошибку. При ошибке доступен повторный звонок, при блокировке воспроизведения браузером — отдельная кнопка включения звука/видео.
- Кнопки звонка увеличены; локальное видео больше не перекрывает описание состояния.

## Установка обновления

1. Сделайте резервную копию существующего проекта, базы данных и настроек сервера.
2. Распакуйте ZIP. Обновите клиент целиком, включая новые файлы `client/js/usability.js` и `client/css/usability.css`, изменённые `index.html` и `sw.js`. Для GitHub Pages используйте прежнюю схему публикации папки client.
3. Обновите серверный код и `server/public`, затем перезапустите сервер. Серверное изменение необходимо для сохранения подписей к файлам. Не заменяйте рабочую базу данных, переменные окружения, адрес сервера и параметры TURN тестовыми значениями.
4. Перезагрузите страницу приложения после публикации. Сервис-воркер использует новый номер кеша.

Это исходники веб-приложения, а не установщик Windows. Не запускайте приложение двойным щелчком по index.html: используйте опубликованный HTTPS-адрес или локальный HTTP-сервер для разработки.

## Проверено и ограничения

В изолированном Edge с тестовыми ответами API проверены: предпросмотр, явная отправка, подпись с экранированием HTML, отмена и подтверждение удаления, ограничения размера видео, закрытие по Escape, отображение ошибки звонка и мобильная ширина 390 px. Проверен синтаксис нового JavaScript и сервера.

Реальные звонки между двумя устройствами, доставка файлов через рабочий сервер и разные мобильные браузеры этой проверкой не покрыты. Обновление улучшает интерфейс, но не гарантирует устранение проблем сетевого соединения и не добавляет сквозное шифрование. Перед использованием проверьте звонок и обмен файлами двумя тестовыми аккаунтами.
