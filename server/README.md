# Family Server😍

Node.js сервер для Family.

## Запуск
```bash
npm install
npm start
```

Порт: `8000`.

## Persistent data
`data/family.json` — пользователи, чаты, аватары, голосовые сообщения и подписки push.
`data/vapid.json` — автоматически созданные VAPID-ключи Web Push. На Railway нужен persistent volume, чтобы ключ не менялся после redeploy.

## Шифрование базы сообщений

Укажите на Railway переменную окружения `FAMILY_DB_ENCRYPTION_KEY` (случайная длинная секретная строка). После следующего сохранения `data/family.json` будет храниться в AES-256-GCM. Не меняйте и не теряйте этот ключ: без него базу нельзя прочитать. Это защищает данные на диске; HTTPS уже защищает передачу. Полное E2E-шифрование потребует отдельного хранения ключей на каждом устройстве.

## Push
Сервер использует стандартный Web Push через пакет `web-push`. Для iPhone приложение должно быть добавлено на Home Screen и разрешение на уведомления выдано через кнопку в Family.
